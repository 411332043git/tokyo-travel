# 東京智慧旅遊全能助手 (Tokyo Travel Agent) 需求說明

## 1. 專案目標與定位
專為日本東京自由行打造的多模態智慧 Agent。使用者可透過 Discord 發送文字或拍照上傳圖片，Agent 自動完成日語即時翻譯、精品台日即時比價、東京地鐵與站內導航、日本藥妝辨識，並將歷次查詢與辨識結果自動存入 Excel 檔案累加記錄。

## 2. 核心功能模組

### 模組 1：日語即時雙向翻譯（文字 / 拍照對照）
- 圖片翻譯：上傳日文菜單、招牌、車廂告示或說明書照片，辨識出日文原文並提供精準繁體中文翻譯與重點摘要。
- 中文轉日語對話：使用者輸入中文對話（如想對店員說的話），Agent 同時回傳中文原句、實用日文句型，並附上「平假名」與「羅馬拼音 (Romaji)」，方便開口唸或直接出示手機螢幕給店員看。

### 模組 2：精品品牌辨識與台日即時比價
- 拍照辨識：上傳精品包款、手錶、飾品或專櫃吊牌照片。
- 價格對比與估算：
  - 日本專櫃定價（JPY 含稅價與預估退稅價）。
  - 台灣官方專櫃參考價（TWD）。
  - 換算台幣實際差額與折扣幅度（省約多少台幣、約幾折）。
- 法規與退稅提醒：日本機場退稅新規（先付含稅價，於出境機場海關查驗退稅；百貨公司退稅手續費約 1.55%）與台灣海關免稅額（每人 3.5 萬台幣上限）。

### 模組 3：東京地鐵與站內導航
- 路線規劃：文字詢問兩地交通（如「從人形町到澀谷」），Agent 提供最推薦搭乘路線（Tokyo Metro / 都營地下鐵 / JR）、線路顏色與代號（如 H、G 線）、轉乘站與建議出口。
- 車站指示牌辨識：上傳站內複雜的箭頭或指標照片，清楚指出該往哪個方向或月台走。

### 模組 4：日本藥妝與購物掃描
- 拍照上傳藥妝、保健品或保養品外盒，辨識品名、核心功效、服用方法/劑量與使用警語。
- 台灣入境攜帶限量提醒（非處方藥每種限 12 瓶/盒，總數不超過 36 瓶/盒）。

## 3. 資料儲存與 Excel 記錄
- 每次 Agent 完成辨識或查詢後，自動將結果存入資料夾（DATA_DIR）內的 Excel 檔案。
- Excel 檔案必須支援持續往下累加（Append），每次重啟或新紀錄都不會覆蓋舊資料。
- 儲存欄位：
  1. 查詢時間 (Timestamp)
  2. 使用者 ID / 名稱
  3. 模式類別 (日語翻譯 / 精品比價 / 地鐵導航 / 藥妝辨識)
  4. 查詢內容 / 辨識品名
  5. 關鍵結果 (價格差額 / 日文翻譯 / 推薦路線等)
  6. 備註 / 法規提醒

## 4. 系統規範與安全防護
- 語言支援：預設使用繁體中文；若使用者輸入 "English"，切換至全英文模式。
- 非相關內容處理：若上傳非旅遊/精品/藥妝/交通/日文圖片，Agent 友善提示並記錄為「未知類別」。
- 四段安全防護：
  1. 防護 1：claude -p 不應該能讀到 DATA_DIR 裡別人的照片和紀錄。
  2. 防護 2：上傳者打的字只能當「資料」，不能被當成給 claude -p 的指令。
  3. 防護 3：claude -p 回來的品名拿到當檔名前，要清掉會造成路徑亂跑的字（/ \ .. 冒號等）。
  4. 防護 4：寫進 Excel 的文字若以 = + - @ 開頭，要處理成純文字，避免開 Excel 時被當公式。
