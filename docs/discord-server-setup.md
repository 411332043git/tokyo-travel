# Discord 伺服器設定步驟

目標：建立你自己的 Discord 伺服器（Server）、一個給 Agent 用的頻道，拿到 `CHANNEL_ID`，並產生邀請連結讓同組同學加入。

> **名詞**
> - **Server（伺服器）**：Discord 裡一個獨立的「社團空間」，你是擁有者。
> - **Channel（頻道）**：伺服器裡的一個聊天室。
> - **ID**：Discord 給每個東西（頻道、使用者）的一串長數字，程式靠它認人認頻道。

> **介面文字**：下面每個按鈕都先寫英文、再寫中文（括號內）。如果你的 Discord 是中文介面，看括號內的字；畫面和步驟有些微不同是正常的，Discord 偶爾會改版。

> **準備**：用電腦版 Discord App，或是瀏覽器開 <https://discord.com/app>，並且已經登入你的帳號。

---

## 一、建立你自己的 Server

1. 看 Discord 視窗**最左邊**那一排圓形圖示。拉到最下面，點那個 **綠色加號 `+`**（Add a Server／新增伺服器）。
2. 跳出視窗，點最上面的 **Create My Own**（自己建立）。
3. 下一頁問「這個伺服器是做什麼用的」，點 **For me and my friends**（供我和我的朋友使用）。
4. 在 **Server Name**（伺服器名稱）欄位輸入名稱，例如 `東京旅遊測試`。
5. 點右下角的 **Create**（建立）。
6. 你會直接進入新伺服器，左邊那一排圓形圖示多了一個，這就是你的伺服器。

> 你自動就是這個伺服器的擁有者，擁有最高權限。

---

## 二、建立給 Agent 用的頻道

新伺服器預設有 `#general`（一般）頻道。我們另外建一個專用的，避免 Agent 在別的頻道亂回應。

1. 看畫面**左邊第二欄**（頻道清單）。找到 **TEXT CHANNELS**（文字頻道）這一行。
2. 把滑鼠移到這一行，右邊會出現一個 **`+`**。點它（Create Channel／建立頻道）。
3. **Channel Type**（頻道類型）選 **Text**（文字）。
4. **Channel Name**（頻道名稱）輸入 `tokyo-travel`（Discord 頻道名稱只用小寫英文、數字和連字號）。
5. **Private Channel**（私人頻道）這個開關**保持關閉**。
   > 打開的話，同學要另外被授權才看得到；之後 Agent 本身也要另外加權限，初期測試會多很多麻煩。
6. 點 **Create Channel**（建立頻道）。
7. 左邊頻道清單會出現 `# tokyo-travel`，點它進去，之後所有測試都在這裡。

---

## 三、打開開發者模式，拿到 CHANNEL_ID

Discord 預設把 ID 藏起來。要先打開「開發者模式」才找得到。

### 3.1 打開開發者模式（只需做一次）

1. 看視窗**左下角**，你的頭像和名字旁邊有一個 **齒輪**圖示（User Settings／使用者設定）。點它。
2. 在左邊清單往下找到 **Advanced**（進階），點它。
3. 把 **Developer Mode**（開發者模式）的開關**打開**（變成綠色）。
4. 按右上角的 **X**（或鍵盤 `Esc`）關閉設定。

### 3.2 複製 CHANNEL_ID

1. 在頻道清單，**對 `# tokyo-travel` 按滑鼠右鍵**。
2. 在選單最下面點 **Copy Channel ID**（複製頻道 ID）。
3. 打開 `.env` 檔，把數字貼在 `CHANNEL_ID=` 的後面，例如：

   ```
   CHANNEL_ID=123456789012345678
   ```

   （數字大約 18～19 位。`.env` 還沒建立的話，等程式部分開始時再一起建。先貼到記事本暫存也可以。）

> `CHANNEL_ID` 不是密碼，外洩風險低，但沒必要公開貼出來。

### 3.3 順便複製你自己的 ID（之後會用到）

Agent 需要知道「誰是擁有者」，對應 `.env` 的 `OWNER_ID`。

1. 在右邊成員清單（或任何訊息）找到**你自己的名字**。
2. 對它按滑鼠右鍵，點最下面的 **Copy User ID**（複製使用者 ID）。
3. 貼到記事本，標註「OWNER_ID」，暫存起來。

## 四、產生邀請連結，讓同學加入

> 這個連結是邀請同學**進入你的伺服器**。同學進來後，還不能使用 Agent，要再用 Agent 的「邀請碼」授權（見 `docs/architecture.md` 第 12 節與訪談 Q20）。這兩件事是分開的。

1. 在左邊伺服器清單找到你的伺服器。看頻道清單**最上方**，伺服器名稱旁邊有一個向下的小箭頭 **`⌄`**，點它（或直接對伺服器名稱按左鍵）。
2. 在選單點 **Invite People**（邀請其他人）。
3. 跳出視窗後，最下面有一行連結，例如 `https://discord.gg/xxxxxxx`。
4. 為了安全，**先改設定再複製**：點視窗底部的 **Edit invite link**（編輯邀請連結），或視窗右下角的 **齒輪**圖示。
5. 設定：
   - **Expire After**（到期時間）：選 **7 days**（7 天）。
   - **Max Number of Uses**（最多使用次數）：選你組員的人數，例如 **5 uses**（5 次）。
   - **Grant temporary membership**（授予暫時成員資格）：**不要勾**，否則同學一離線就被踢掉。
6. 點 **Generate a New Link**（產生新連結）。
7. 點 **Copy**（複製），把連結傳給同組同學（例如通訊軟體）。

### 同學收到連結後

1. 點連結，選 **Open in Discord**（在 Discord 開啟）或直接在網頁開啟，並登入自己的帳號。
2. 按 **Accept Invite**（接受邀請）。
3. 他們會進到你的伺服器，點左邊 `# tokyo-travel` 就能看到頻道。

### 邀請連結用完之後

- 測試結束，到 **Invite People → Edit invite link** 把連結關掉；或到伺服器名稱選單 → **Server Settings**（伺服器設定）→ **Invites**（邀請）→ 對連結按 **X** 刪除。

---

## 五、完成檢查

- [ ] 左邊伺服器清單看得到你的伺服器。
- [ ] 有 `# tokyo-travel` 頻道，且 Private Channel 沒開。
- [ ] 已打開開發者模式。
- [ ] 已複製並暫存 `CHANNEL_ID` 和你自己的 `OWNER_ID`。
- [ ] 邀請連結已設定 7 天、限次數，並傳給同學。
